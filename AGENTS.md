# AGENTS.md

## Scope
These instructions apply to the entire repository.

## Project phase
The repository is currently in scaffold/planning mode.

## Rules for contributors
- Do not add production implementation code until explicitly requested.
- Prefer documentation, interfaces, and TODO planning artifacts.
- Keep folder structure clean and minimal.
- If adding scripts, keep them non-destructive and documented.
- Add concise commit messages that describe scaffold changes clearly.

## Validation
- Run lightweight checks (e.g., file tree and git status) before committing.
